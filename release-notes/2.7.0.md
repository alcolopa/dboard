# dboard 2.7.0

- Review the target database and existing tables before running a MySQL or MariaDB restore. Preflight blocks dboard exports that assign values to generated columns.
- Restore failures show the failing SQL, how many statements succeeded, and when to use a fresh or reset target.
- Connection diagnostics identify SSH authentication, TLS, and database login failures when the client reports the cause.
- Browse for an SSH private key and show or hide the connection password while editing a connection.
- MySQL query results display spatial points as readable coordinates. Database exports let the server recompute generated values during restore.
