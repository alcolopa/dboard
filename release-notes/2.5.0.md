# dboard 2.5.0

- Open directly on the connections dashboard without reconnecting previous sessions.
- Organize saved connections into custom folders and add comma-separated tags.
  Search matches folders and tags as well as connection names, hosts and environments.
- Enable destructive-action confirmation for individual connections independently
  of their environment. Existing production/staging safeguards and read-only mode
  remain available.

Existing connection files load with empty folders and tags and retain their
existing environment-based safeguards. Connect explicitly after launching the app.
