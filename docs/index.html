A native database client
for macOS, Windows and Linux

dboard is a fast, native client for PostgreSQL, MySQL, and MongoDB, inspired by Sequel Pro. Edit data in place, with safeguards that stop you from running a destructive statement against production by accident. Now available on Windows and Linux as well as macOS.

Three-pane workspace · Connection sidebar · Query editor · Live inspector

Zero-friction editing

No Save button. Every change writes to the database the moment you confirm it.

⚡

Instant Cell Editing

Double-click or press Enter to edit any cell. Tab, Enter, or click away and the write executes immediately, with inline spinner, checkmark, and error states.

🔑

Safe Automatic Writes

Detects primary keys — including composite keys — and uses strict parameterized statements. Tables without a unique identifier are locked from inline mutation.

↩︎

Reversible Undo

Every cell update, row insert, and DDL execution is recorded. ⌘Z reverts the actual database operation, not just the UI state.

🛡️

Production Guardrails

Tag connections as Production, Staging, Development, or Local. Destructive statements against Production require a typed confirmation.

🔐

Keychain-Backed Secrets

Passwords go into the OS keychain (macOS Keychain, Windows Credential Manager, or Secret Service on Linux) and are never logged or written to disk in plaintext.

🔍

Command Palette & Search

Ctrl/⌘+K for fuzzy command and connection switching, Ctrl/⌘+P for instant global search across tables, columns, routines, and views.

Download

Each tagged version is built by GitHub Actions and attached to the release page.

macOS

Separate builds for Apple Silicon and Intel Macs. Unzip it and drag it to Applications.

The build is unsigned. Run xattr -cr dboard.app once to get past Gatekeeper.

Apple SiliconIntel

Windows

Setup installer for x64 and ARM64: Start menu entry, optional desktop shortcut, uninstaller. No runtime to install.

CI builds this, but it hasn't been tested by hand on Windows yet. Bug reports welcome.

x64 installerARM64 installer

Linux

Packages for Debian/Ubuntu (.deb), Fedora (.rpm) and Arch (.pkg.tar.zst, x64), plus a tar.gz with an installer script for other distros. x64 and ARM64. Built with Rust and Slint, so it runs on X11 and Wayland.

Extract it and run ./dboard. Saved passwords need a Secret Service keyring.

.deb x64 .rpm x64 Arch x64 .tar.gz x64 .deb ARM64 .rpm ARM64 .tar.gz ARM64

One Rust + Slint codebase serves every platform, in dboard-cross. SSH tunnels and SQL syntax highlighting are not there yet. Or build from source.
