# Real desktop captures

Captured from the locally built dboard macOS app using an isolated configuration and a seeded SQLite database. All names and email addresses are fictional demo data. JPEG files are full window captures, with no reconstructed UI or generated elements.

Each workflow has light and dark captures: table browser and activity inspector, SQL editor, relationship diagram, and command palette. The light SQL capture contains a sample query; the dark SQL capture shows a new query tab. Neither claims an executed result.

Colors on the website are sourced from `dboard-cross/crates/app/ui/theme.slint`. Engine-specific features are described in the feature guide; these SQLite captures do not verify server access management or every database engine.
