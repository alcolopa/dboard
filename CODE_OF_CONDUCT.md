# Community code of conduct

Be respectful, specific and constructive in issues, pull requests and other project spaces. Welcome people with different backgrounds and experience levels. Critique ideas and code, and respect people's privacy.

Harassment, discriminatory language, threats, sexualized content, personal attacks and publishing private information are not acceptable.

Maintainers may edit or remove content, close discussions, or restrict participation in response to violations. Responses should reflect the severity and context of the behavior.

To report a concern, contact a repository maintainer privately through a contact method on their GitHub profile. If none is available, ask for a private channel without publishing sensitive details. Maintainers involved in a report should not decide its outcome.
