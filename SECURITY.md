# Security reporting

Do not post exploitable vulnerabilities, credentials or private database data in public issues.

Use GitHub's **Report a vulnerability** option in the repository's **Security** tab when private reporting is enabled: https://github.com/alcolopa/dboard/security/advisories/new.

If private reporting is unavailable, open an issue asking for a private contact method without including exploit details. Share the affected version, operating system, database engine and a sanitized reproduction privately once a channel is established.

Security fixes focus on the latest version; older versions have no guaranteed backport support. There is no guaranteed response time. For ordinary bugs without security impact, use the bug report template.
